Built like a real password manager

Everything you expect from a modern vault, in a clean Django codebase you can read in an afternoon.

Encrypted at rest

Secrets and notes are encrypted with Fernet (AES + HMAC) and support zero-downtime key rotation via MultiFernet.

Security health

Spot weak, reused and stale passwords instantly — reuse is detected with keyed fingerprints, never by decrypting everything.

Password generator

Cryptographically secure passwords and memorable passphrases, with live entropy scoring.

Audit trail

Every sign-in, reveal, copy, edit and export is logged with IP and timestamp so nothing happens silently.

Hardened by default

Brute-force lockout, auto-locking sessions, CSRF protection, strict cookies and owner-scoped data access.

REST API

A full Django REST Framework API with JWT auth for building mobile apps, CLIs or browser extensions on top.
